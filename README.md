# Stainy Resume Drafter

## Getting Started
Step 1: Clone the repo
```
git clone https://github.com/IsaiahStain05/ResumeBuilder.git
```
Step 2: CD into the newly cloned directory
```
cd ResumeBuilder
```

Step 4: Install all required imports
```
npm install
```

Step 3: Start electron and node concurrently
```
npm start
```

You're done! The electron app should open at this point.

## Walkthrough

 - To create an account, enter your desired credentials and press sign up. ***Please remember your password and username - we do not currently have any way to recover your account if lost.***
 - You are free to enter all information in on the page **WITHOUT** a Gemini API key. You can still use the website as a normal resume formatting website - but we really shine when you do enter an API Key
 - To get an API key, please go to https://aistudio.google.com/apikey to get your individual Gemini API key. Do ***NOT*** set up a billing account for your project, all AI review for your resume can (and should) be done on the free tier.
